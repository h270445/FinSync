# UI design exports

Approved screen designs exported from Figma. The Figma file is the source of truth; this folder holds only the images the documentation and thesis reference.

- Figma file: *link to be added*
- Screen list and purpose: [user-interface.md](../user-interface.md#screens)

## Rules

- Commit only **approved** frames, as PNG (2x at most, ideally under 500 KB each). SVG only for icons or diagrams.
- File name: `<screen-id>-<short-name>-v<version>.png`, for example `w5-review-queue-v1.png`. A changed design gets a new version; old versions stay so the thesis can show iterations.
- Work-in-progress and bulk exports go to `exports/` in this folder, which is ignored by git (proposed rule: `docs/design/ui/exports/` in `.gitignore`).
- Never commit `.fig` files. Figma Make code goes into `web/` only after it is rewritten and reviewed ([user-interface.md](../user-interface.md#technology-proposed)).
- Only synthetic data on screens; no real names, account numbers or amounts.
