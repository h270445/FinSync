# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-09

## Context

The thesis must explain why the system is built the way it is, and the work continues into Szakdolgozat II. Reasons behind decisions are easily lost between semesters.

## Decision

Record significant architecture decisions as short Architecture Decision Records in `docs/architecture/decisions/`, using the template in the folder README.

## Consequences

- The thesis text can cite the records directly.
- A decision that changes later gets a new record that supersedes the old one, so the history stays visible.
