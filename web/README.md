# FinSync web app

The member-facing web client: React 19, TypeScript, Vite, Tailwind CSS 4 and shadcn/ui, with TanStack Query for server state. UI text is Hungarian. Screens and their purpose: [docs/design/user-interface.md](../docs/design/user-interface.md#web-app).

## Run it

Requirements: Node.js 22 and the backend's requirements (see [getting started](../docs/guides/getting-started.md)).

```bash
# Terminal 1, repository root: the API on port 8080
python -m finsync.api

# Terminal 2: a token for the sign-in screen
python -m finsync.api.tokens create --user anna --group lakas --name "Webes fejlesztés"

# Terminal 3, web/
npm install
npm run dev        # http://localhost:5173
```

The Vite dev server forwards `/v1` to `http://127.0.0.1:8080` (override with `FINSYNC_API`), so the browser talks to one origin and the API needs no CORS rules.

**Sign-in is temporary.** Until password login with an HttpOnly session cookie exists (W1, M2), the sign-in screen takes an API token and keeps it in `sessionStorage` for the tab. That is acceptable for local development only; the [technology stack](../docs/architecture/technology-stack.md) explains why a browser must not keep long-lived secrets in JavaScript-readable storage.

## API types

`src/api/schema.d.ts` is generated by [openapi-typescript](https://openapi-ts.dev) from the FastAPI schema, and `src/api/client.ts` wraps it with `openapi-fetch`, so a request or response that does not match the backend fails the type check. After changing a backend model or endpoint:

```bash
npm run gen:api    # runs `python -m finsync.api --openapi`, writes openapi.json and src/api/schema.d.ts
```

Both files are committed, so the diff shows how the API changed. Set `PYTHON` if `python` on the PATH is not the project's interpreter.

## Layout

```text
src/api/          generated schema, typed client, TanStack Query hooks
src/auth/         development token sign-in
src/components/   app shell, badges, loading/error/empty states; ui/ holds shadcn/ui components
src/lib/          Hungarian formatting (amounts, dates, scores) and event helpers
src/pages/        one file per screen
```

shadcn/ui components are copied into `src/components/ui/` by its CLI (`npx shadcn@latest add <name>`) and may be edited; the current shadcn style builds on Base UI primitives. Visual rules (teal as the only accent, amber only for "needs review", system font) are in `src/index.css`.
